MATHEMATICAL MODEL

數學模型

令每一步的移動量為隨機變數 \(Y_i\)，向右移動為 +1，向左移動為 −1。

Xn = X0 + ∑i=1n Yi

P(Yi = 1) = p,   P(Yi = −1) = 1 − p

E[Xn] = X0 + n(2p − 1)

Var(Xn) = 4np(1 − p)

本模擬器從 X₀ = 0 開始，並假設每一步的移動彼此獨立且具有相同分布。

ABOUT THIS PROJECT

About Random Walk Lab

Random Walk Lab 是一個以機率與隨機過程為主題的互動學習小專案。使用者可以調整參數、觀察樣本路徑，並將模擬統計量與數學理論進行比較。
